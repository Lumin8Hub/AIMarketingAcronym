# AI Marketing Acronym Deck

A navigable React web presentation for **The State of AI for Marketing in 2026**, adapted from the supplied outline and Acronym design system.

## Run locally

`npm install`
`npm run dev`

Use the on-screen controls, slide rail, or keyboard arrows to navigate.

## Deploy to GitHub Pages

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds the app with Vite and deploys `dist/` to GitHub Pages.

After merging, enable **Settings → Pages → Source: GitHub Actions** if it is not already enabled.
